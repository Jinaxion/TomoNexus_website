プライバシーポリシー

制定日：2026年10月21日

TomoNexus の作者（以下「作者」）は、アプリケーション「TomoNexus」（以下「本ソフトウェア」）および公式サイト（以下「本サイト」）における情報の取り扱いを、以下のとおり定めます。

ひとことで言うと：作者は、あなたの会話・メモ・音声・APIキーを受け取りません。メモと記憶はあなたの PC に保存され、外に出るのは、会話のために利用者自身が契約した AI・音声サービス（Anthropic・Azure・任意で Groq）への通信だけです。データの流れは しくみ のページで図解しています。

1. 作者が取得する情報

本ソフトウェアには、作者のサーバーへ会話・メモ・音声・学習記録・APIキーを送る仕組みはありません。作者がこれらの情報を取得・保存することはありません。

なお、本ソフトウェアは起動時に、新しい版の有無を確かめるため、作者が GitHub Pages に置いている版情報ファイル（https://jinaxion.github.io/TomoNexus-update/update.json）を読み込みます。このとき送られるのは、ふつうの Web アクセスと同じ通信情報（IPアドレス等）だけで、会話・メモ・利用状況などは送りません。アクセスの記録は GitHub, Inc. が取り扱います。作者は個々のアクセスを記録・分析していません。

2. あなたの PC に保存される情報

次の情報は、利用者の PC（利用者が指定したフォルダ）に保存されます。保存先にクラウド同期フォルダを指定した場合は、そのサービスの取り扱いに従います。

  • メモと「記憶」（ふつうの .md ファイル。Obsidian の Vault、またはアプリ内の保存先）
  • 学習記録・単語帳・好感度・XP・連続日数
  • VRM と各種設定
  • APIキー（Windows の資格情報マネージャー）

会話の音声は保存しません（聞き取りのために送信するだけです）。アンインストール時にデータも消す場合は、アプリのフォルダに加えて %APPDATA%\Tomo を削除してください。

3. 外部サービスへの送信

本ソフトウェアは、利用者が設定した次のサービスに、機能の提供に必要な情報を送信します。送信先での取り扱いは各社の規約・ポリシーに従います。

送信先使いみち送る情報各社の定め
Anthropic（Claude）会話の頭脳、要点のまとめ、メモの提案、Web検索会話の文章、メモにまとめる内容、記憶の一部（会話の文脈として）Privacy Policy
Microsoft Azure Speech話した言葉の文字起こし（聞き取り）、キャラの声（読み上げ）話した音声、読み上げる文章Speech to text のデータとプライバシー
Groq（任意）聞き取りの予備（Azure の無料枠を超えた月など）話した音声Your Data in GroqCloud

各社の取り扱いの概要（2026年10月21日時点で作者が各社の公開情報から確認したもの。最新の内容は各社の定めをご確認ください）：

  • Azure Speech（聞き取り）：リアルタイムの文字起こしでは、音声はサーバーのメモリ上で処理され、Microsoft はデータを保存しないとされています。
  • Groq：既定では推論リクエストのデータを保持しないとされています。ただし、障害対応や不正利用の調査のため、最大30日間ログが保持される場合があります。

読み上げをオフにしてキーボードで会話する設定では、外部に送信されるのは Anthropic への文章だけになります。

4. AIの学習に使われるか

  • ① Anthropic の APIキーで使う場合：Anthropic の商用規約が適用され、送った内容が AI の学習に使われることはありません（標準の保持期間は30日）。
  • ② Claude Pro / Max など（個人向けプラン）で使う場合：Anthropic の一般向け規約が適用されます。claude.ai の設定で「モデル改善に協力」がオンだと、会話が学習に使われ5年間保持されます。オフの場合の保持期間は30日です。気になる方は プライバシー設定 でオフにしてからご利用ください。
  • ② Claude Team で使う場合：商用規約が適用され、学習に使われません。

本ソフトウェアが Claude のログイン情報（パスワード・トークン）を読んだり預かったりすることはありません。

5. APIキーとログ

  • APIキーは Windows の資格情報マネージャーに保存し、設定ファイルに平文で書き込みません。
  • 本ソフトウェアのログには、会話・メモ本文・APIキーを記録しません。

6. 購入時の情報

製品版の購入は BOOTH（ピクシブ株式会社）を通じて行われ、決済情報・注文情報の取り扱いは BOOTH および pixiv の規約・プライバシーポリシーに従います。作者は、BOOTH から提供される範囲の注文情報を、ライセンスの発行・お問い合わせ対応のためにのみ利用します。

7. 本サイトについて

  • 本サイトは GitHub Pages（GitHub, Inc.）で公開しています。アクセスの際、GitHub がアクセスログ（IPアドレス等）を記録することがあります。
  • 本サイトは、文字の表示に Google Fonts を、動画の表示に YouTube の埋め込みプレーヤーを利用しています。これらの読み込みや再生にともない、Google にアクセス情報が送信され、Cookie が使われることがあります。
  • 作者は、本サイトで独自のアクセス解析や Cookie を使用していません。

8. お問い合わせで受け取る情報

お問い合わせの際にいただいた情報（お名前・連絡先・内容など）は、回答と不具合の調査のためにのみ利用し、法令に基づく場合を除き第三者に提供しません。

9. ご注意いただきたいこと

会話の内容は AI サービスに送信されます。AI に個人情報やパスワード等を話したり入力したりしないでください。

10. 改定

本ポリシーは、必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点から効力を生じます。

11. お問い合わせ

本ポリシーに関するお問い合わせは、BOOTH のショップ（jinaxion.booth.pm）からご連絡ください。
